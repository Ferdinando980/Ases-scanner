# Architecture Recovery

Recover architecture from evidence, not directory-name stereotypes alone.

Prefer:
- import/dependency direction;
- framework wiring;
- runtime configuration;
- route/event registrations;
- persistence adapters;
- deployment/config manifests;
- tests crossing modules.

Output confidence and evidence for every material conclusion.
