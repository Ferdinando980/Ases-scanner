# Documentation Bootstrapper

Possible outputs:
- recovered system overview
- RAD
- SDD
- ODD
- testing baseline
- traceability
- open questions

Rules:
- recovered docs are not original historical requirements;
- label inferred requirements;
- omit empty/ceremonial sections;
- prefer concise diagrams/tables where useful;
- maximum recoverable truth, minimum useless documentation.
