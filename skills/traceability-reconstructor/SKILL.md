# Traceability Reconstructor

Minimum graph:
behavior ↔ code ↔ test

When evidence permits:
recovered requirement/use-case ↔ component ↔ class/interface ↔ code ↔ test.

Detect missing tests, orphan behavior, orphan code, and stale links.
